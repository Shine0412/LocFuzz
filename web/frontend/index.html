📖 指标说明（点击展开）
  • 用例有效性：LLM 生成的变异代码中，能被 JS 引擎正常解析并执行（非语法错误、未超时/崩溃）的比例。越高说明 LLM 定向变异越精准、不破坏代码结构。
  • Jaccard 相似度：变异前后覆盖函数集合的重合度（交集 ÷ 并集）。越接近 100%，说明变异保留了原漏洞样本的执行路径。
  • EditSim 相似度：变异前后函数调用序列的编辑距离相似度。越高说明变异没有打乱原漏洞的触发时序。
  • 两项相似度共同回答：变异是否"换汤不换药"地在原漏洞附近探索——这是挖漏洞变体的关键。
  • LLM 延迟：每次调用大模型完成"语义分析 + 位置选择 + 变异"的耗时（毫秒）。
